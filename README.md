# Журнал ТОиР — офлайн-приложение для осмотра оборудования

Механик сканирует QR-метку на агрегате, проходит чек-лист, отмечает замечания и делает фото.
Интернет не нужен: всё хранится в памяти телефона. Данные передаются мастеру файлом.

## 1. Разместить на GitHub Pages (один раз, ~10 минут)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите **New repository** → имя `toir` → **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащите **все файлы и папки** из этого архива
   (все 13 файлов, папок нет) → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты приложение доступно по адресу `https://ВАШ-ЛОГИН.github.io/toir/`.

## 2. Установить на телефон

Интернет нужен только при первой установке.

**Android (Chrome):** откройте адрес → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

**iPhone (Safari):** откройте адрес → кнопка «Поделиться» → **На экран «Домой»**.
На iPhone всегда открывайте журнал с иконки и сканируйте метки кнопкой «Сканировать» внутри приложения:
у Safari и у иконки отдельная память.

После установки проверьте: включите «Авиарежим» и откройте приложение — оно должно работать.

## 3. QR-метки

Вкладка **«Оборудование и QR»** → «Лист для печати» → откройте файл на компьютере → Ctrl+P.
Печатайте метки из версии на GitHub (не из локальной копии): в метку зашит адрес приложения.

## 4. Передача данных

- **Механик:** вкладка «Передача» → **Отправить новые** → выбрать мессенджер/почту → отправить мастеру.
  Интернет нужен только в этот момент.
- **Мастер (на компьютере):** откройте тот же адрес в Chrome/Edge → «Передача» → **Выбрать файлы** → выделите все
  полученные .json. Повторы не задваиваются. Затем **Выгрузить всё в Excel**.

## 5. Изменения

- **Новый агрегат для всех:** добавьте строку в `equipment.js` (или скачайте его из приложения),
  загрузите на GitHub и увеличьте версию в `sw.js` (`toir-v2` → `toir-v3`).
- **Новая модель / чек-лист:** раздел `MODELS` в `app.js`.
- Телефоны получат обновление при следующем выходе в интернет (появится кнопка «Обновить»).

## Важно

- Данные хранятся только на телефоне, пока их не передали. Передавайте осмотры хотя бы раз в смену.
- Не удаляйте приложение и не очищайте данные браузера, пока есть непереданные осмотры.
- Порог температуры подшипников 70 °C — ориентир; сверьте с паспортом дробилки.
