# МДСЗ-8 · Обходы (демо)

Офлайн-приложение для телефона смены МДСЗ-8, ПК «Гаврилово».
Отчёт смены приходит письмом на почту и собирается в «Сводный журнал МДСЗ-8» через Power Query.

## 1. Разместить на GitHub (один раз)

1. github.com → **New repository** → имя `mdsz8` → **Public** → Create.
2. **Add file → Upload files** → перетащить ВСЕ файлы из архива (15 шт., без папок) → Commit.
3. **Settings → Pages** → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение доступно по адресу: **https://vovka-6.github.io/mdsz8/**

Прежнее приложение (vovka-6.github.io/toir) остаётся как было.

## 2. Установить на телефон

Chrome → открыть адрес → меню ⋮ → **Добавить на главный экран → Установить**.
Дальше работает без интернета. Интернет нужен только для отправки письма.

## 4. Как уходит отчёт

Мастер (в ремонтную смену — механик) → **📨 Закрыть смену и отправить**:
1. **⬇ Скачать отчёт и фото** — файлы попадут в «Загрузки» телефона.
2. **✉ Открыть письмо** — адрес, тема и текст подставятся сами.
3. В письме 📎 → «Загрузки» → выбрать `МДСЗ8_…xlsx` и фото → Отправить.
4. **✓ Письмо отправлено**.

Почему не одной кнопкой «Поделиться»: Chrome на Android не разрешает передавать через «Поделиться» файлы Excel. Это ограничение браузера.

Неотправленные отчёты лежат в **Архив отчётов**, их можно отправить повторно.

## 5. На компьютере

1. Открыть письмо в почте mail.ru → скачать вложения в папку **МДСЗ-8 Отчёты** (xlsx и фото в одну папку).
2. Открыть «Сводный журнал МДСЗ-8.xlsx» → лист «Настройки» → путь к этой папке.
3. **Данные → Обновить всё**.

## Файл отчёта

`МДСЗ8_ГГГГ-ММ-ДД_С{№}_{Техн|Рем}.xlsx`, листы:
- **Дефекты**: новые, изменённые за смену и все открытые;
- **Обходы**;
- **Замеры**;
- **Точки обхода**: время на каждой КТ, только для просмотра, в Сводный журнал не загружается.

Фото: `КТ_ГГГГММДД_ЧЧММ_Dnnn.jpg`.

## Обновление приложения

Изменили файлы на GitHub → в `sw.js` увеличить `VERSION` (mdsz8-v1 → mdsz8-v2).
Телефон покажет «Доступно обновление».
Данные на телефоне при обновлении сохраняются.
