# МДСЗ-8 · Обходы (демо)

Офлайн-приложение для телефона смены МДСЗ-8.
Отчёт смены приходит письмом на почту и собирается в «Сводный журнал МДСЗ-8» через Power Query.

## 1. Что лежит на GitHub, а что — только на телефоне

Сайт на GitHub открыт всем, у кого есть ссылка. Поэтому здесь только код приложения.

**Никогда не выкладывайте сюда:** технологическую схему и карты маршрутов, файл настроек (`МДСЗ8_настройки_….json`), файл схем (`МДСЗ8_схемы.json`), реальные ФИО, табельные номера, телефоны, личную почту.

- **Схема и карты маршрутов** загружаются на телефон администратором: Настройки → «Схема и карты маршрутов» → файл `МДСЗ8_схемы.json` (или по одной картинке). Хранятся только на телефоне.
- **Почта для отчётов** (рабочая) задаётся в Настройках телефона. В коде адреса нет.
- **Персонал и ПИН** — только в Настройках телефона.

Перед каждой публикацией GitHub проверяет код Semgrep (`.github/workflows/proverka-i-publikaciya.yml`). Если найдены пароли, ключи, личная почта или картинки .jpg — сайт не обновляется.

## 2. Установить на телефон

Chrome → открыть адрес → меню ⋮ → **Добавить на главный экран → Установить**.
Дальше работает без интернета. Интернет нужен только для отправки письма.

## 3. Демо-вход

| Работник | Должность | ПИН |
|---|---|---|
| Иванов И.И. | Дробильщик | 1111 |
| Смирнов А.А. | Дробильщик | 2222 |
| Петров П.П. | Электрослесарь | 3333 |
| Кузнецов К.К. | Мастер смены | 4444 |
| Сидоров С.С. | Механик | 5555 |
| Орлов О.О. | Зам. начальника ПК (просмотр) | 6666 |

На рабочем телефоне демо-сотрудников удалите или смените им ПИН: эти ПИН видны всем в коде. Стартовый ПИН администратора — 0000, смените его при первом входе.

ПИН на экране не показывается и хранится на телефоне только в зашифрованном виде.

### Права
| Кто | Что может |
|---|---|
| **Администратор** (кнопка «⚙ Вход администратора» внизу экрана входа) | всё: персонал и назначение ответственных 🛡, почта (несколько адресов через запятую), план обходов, нормативы времени, нормы температур, автовыход, перенос настроек на другой телефон, сброс данных |
| **Ответственный 🛡** (по умолчанию — заместитель начальника ПК) | только персонал: ФИО, должности, ПИН |
| Каждый работник | сменить свой ПИН: «🔑 Сменить свой ПИН» |

Стартовый ПИН администратора — **0000**. При первом входе смените его.
Если ПИН администратора забыт, восстановить его нельзя: придётся сбросить данные сайта в Chrome, это сотрёт всё. Поэтому храните файл настроек.

**Настройка нескольких телефонов.** Администратор → ⚙ Все настройки → «Сохранить настройки в файл».
На другом телефоне: «Загрузить настройки из файла». Персонал, ПИН, почта и нормы станут одинаковыми.

После 5 неверных ПИН вход для этого человека блокируется на 1 минуту.

## QR-метки

PDF «QR_метки_МДСЗ-8» — 31 метка, по 6 на листе A4. На каждой: номер и название КТ, код.
В приложении кнопка «📷 Сканировать QR-метку»:
- во время обхода — открывает эту точку и отмечает, что метка отсканирована;
- без обхода — открывает карточку оборудования.

Администратор может включить: «Отмечать точку обхода только после сканирования QR-метки».
В отчёте, на листе «Точки обхода», есть столбец «Метка QR».

## 4. Как уходит отчёт

Мастер (в ремонтную смену — механик) → **📨 Закрыть смену и отправить**:
1. **⬇ Скачать отчёт и фото** — файлы попадут в «Загрузки» телефона.
2. **✉ Открыть письмо** — адрес, тема и текст подставятся сами.
3. В письме 📎 → «Загрузки» → выбрать `МДСЗ8_…xlsx` и фото → Отправить.
4. **✓ Письмо отправлено**.

Почему не одной кнопкой «Поделиться»: Chrome на Android не разрешает передавать через «Поделиться» файлы Excel. Это ограничение браузера.

Неотправленные отчёты лежат в **Архив отчётов**, их можно отправить повторно.

## 5. На компьютере

1. Открыть письмо в рабочей почте → скачать вложения в папку **МДСЗ-8 Отчёты** (xlsx и фото в одну папку).
2. Открыть «Сводный журнал МДСЗ-8.xlsx» → лист «Настройки» → путь к этой папке.
3. **Данные → Обновить всё**.

## Файл отчёта

`МДСЗ8_ГГГГ-ММ-ДД_С{№}_{Техн|Рем}.xlsx`, листы:
- **Дефекты**: новые, изменённые за смену и все открытые;
- **Обходы**;
- **Замеры**;
- **Точки обхода**: время на каждой КТ, только для просмотра, в Сводный журнал не загружается.

Фото: `КТ_ГГГГММДД_ЧЧММ_Dnnn.jpg`.

## Обновление приложения

Изменили файлы на GitHub → в `sw.js` увеличить `VERSION` (mdsz8-v1 → mdsz8-v2).
Телефон покажет «Доступно обновление».
Данные на телефоне при обновлении сохраняются.
